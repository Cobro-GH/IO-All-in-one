卷一秒殺技巧（Drive IMMD_Paper1_MCQ_Hacks）

英語 (A) Comprehension — 定位法＋極端詞排除

  • 先讀題：圈專有名詞、數字、獨特動詞／名詞（Keyword Scanning）。
  • 首尾句定位：主旨／態度題優先看首段、尾段、每段首尾句（演繹式公務文）。
  • 極端詞排除：always / never / all / none / only / must — 除非原文 100% 絕對陳述，否則多數錯；優先 may / some / generally / likely。

英語 (B) Cloze — 前後夾擊＋邏輯連接

  • 看空格左（介詞搭配，如 conduce to）與右（名詞／動詞決定詞性）。
  • 句首／句間：相反→ However / Despite；遞進因果→ Furthermore / Therefore。

自擬 Officers must act in accordance ____ the conditions stamped on the landing slip. 左面是 accordance，固定搭配是 with，不是 to。下一句若以 The passenger, ____, refused to wait. 轉折，空格是 however，不是 furthermore。

英語 (C) Error — 黃金五大考點掃描

考點掃什麼例子
1 主謂一致真正主語（忽略 of / along with）官方樣：normally expects → 應為 expect（在 would 後）
2 平行結構and/or 連接成分詞性對等swimming, running, and playing
3 介詞搭配固定介詞被換in accordance with（非 to）
4 懸垂修飾-ing/-ed 邏輯主語＝主句主語Walking…, the e-Channel…（錯）
5 代詞一致one → he/she；複數一致one… they（錯）

中文 (E)(F) — 成語語境＋偏旁形聲

官方樣只示範形式。下面是自擬對照，用來單獨複習，不是試題原文。

  • 「精神亦從此 ______」→ 無法再振作 → 一蹶不振。附近的「一敗塗地」寫的是局勢，「一落千丈」寫的是程度。
  • 聞雞起舞（開始練功）。錯字常寫成喜舞、喜武、起武。
  • 事情還有辦法，只是一時想不到 → 一籌莫展。錯字「一愁莫展」把「籌」寫成情緒。
  • 依程序、不跳步 → 按部就班。錯字「按步就班」。
  • 急到等不及 → 迫不及待。錯字「迫不急待」。
  • 消息傳得快、沒有腿也能走 → 不脛而走。東西不見了才是「不翼而飛」。兩句不要互填。
  • 一次失敗後繼續按正確方法做 → 再接再厲。越做越過分才是「變本加厲」。

中文 (G) 語病 — 主幹提取＋雙重否定／兩面詞

  • 劃掉定語，只留主語、謂語、賓語。搭配不當就露出來。
  • 兩面詞要對兩面：「能否成功，在於是否努力」。只寫「能否成功，在於努力」就少了一面。

自擬　錯 → 對

  • 警方將舉行一項措施。 → 舉行的是活動；措施用推行。
  • 必須避免不再逾期逗留。 → 「避免」已經是否定，再加「不再」會變成鼓勵逾期。改為「避免逾期逗留」或「不再逾期逗留」。
  • 能否獲准延期，在於文件齊備。 → 改為「能否獲准延期，在於文件是否齊備」。
  • 通過這次行動，使非法勞工受到打擊。 → 缺主語。改為「這次行動打擊了非法勞工」或「部門通過這次行動打擊非法勞工」。

能力傾向 (H) Verbal — 箭頭／三段論畫圈

  • A→B 等價 ~B→~A；否前或肯後不能亂推。
  • All A are B／Some B are C：畫圈，勿憑空想像「有些 A 必然是 C」。
  • 選 True / False / Can’t tell：只根據段落，勿加世界知識。

自擬 前提：所有持 A 符號的人都有居留權。某人有居留權。不能推出他持 A 符號（肯後）。前提：若落地條件是訪客，則不得受僱。某人不是訪客。不能推出他可以受僱（否前；他仍可能是學生或外傭）。

能力傾向 (I) Data Sufficiency — 不計算原則＋決策樹

  1. 單獨 (1) 夠？→ 是則看 (2)：兩皆夠＝D；僅 (1)＝A
  2. (1) 不夠再看 (2)：僅 (2)＝B；兩皆不夠則聯立→夠＝C／不夠＝E
  3. 夠列方程即可停，勿算盡具體數值。

自擬 問：某櫃檯上午平均每小時處理多少人？ (1) 上午 4 小時共 480 人。單獨已夠列式，不必先算出 120。 (2) 下午人流是上午的 1.5 倍。(2) 沒有上午基數，單獨不夠。所以是「僅 (1) 夠」那一類。若改問全日總人數，(1) 和 (2) 各自都不夠、合在一起才夠，那才是聯立的一類。

能力傾向 (J) 圖表 — 單位／分母／尾數估算

  • 先圈單位（thousands / %）。
  • 增長率分母＝舊期（compared to 後面的年份）。
  • 選項個位不同→只算個位；差距大→四捨五入前兩位。

自擬 表上 2024 年為 200（單位：千人次），2025 年為 250。增長率是 (250−200)/200 = 25%，分母是 2024，不是 2025。若單位沒有看成「千」，就會把 50 當成 50 人。選項若是 20%、25%、33%，只需判斷分母是哪一年。
