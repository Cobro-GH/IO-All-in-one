# SOURCE_INDEX — IO Drive 備考材料索引

供「入境事務主任應考網站」流程使用。資料根目錄：`/workspace/io-drive/`；抽出文字：`/workspace/io-drive/extracted/`。

**版權／採用總則**
- **用戶自有筆記**（Notes、Hacks、Angles、CRE Practice、Impromptu、HD notes、Ordinance 整理表）：可充分用於個人備考網站（引用、改寫、做成練習）。
- **Exam Format and Sample Questions**：屬公務員事務局／招聘官方樣本性質 → 網站可**說明考試格式**並做**練習改編**；**不要宣稱整份官方卷全文轉載**。
- 未下載文法教科書：本流程**不處理**。
- 免責：備考參考，非正式官方教材／法律意見。
